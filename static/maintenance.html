学术网站 · 内容更新说明

源内容与网页分开管理。修改 GitHub 仓库中的内容文件并提交后，自动检查、生成并发布网站。无需维护服务器，也无需手动上传每个 HTML。

日常更新：编辑内容文件即可发布

  1. 在你的网站 GitHub 仓库中打开对应内容文件，点击编辑。
  2. 修改内容后点击 Commit changes，提交到 main 分支。只修改内容，不改发布流程。
  3. 在 Actions 查看发布结果；全部检查通过后自动更新线上网站。检查失败时，已有线上版本保持不变。

正式域名及统计接口content/settings.json

同一条记录的标题自动同步到首页、列表、详情页和搜索。项目 Fund 的名称与链接修改 fund_details；活动 Date、Event、Location 与链接修改 activity_details。完整正文在对应 body.html 中编辑。

添加论文、项目、会议或活动

  1. 复制 content/site.json 中同类记录，修改 path、title、日期、作者、摘要、链接及图片。
  2. 在 pages 数组增加相应页面记录，在 content/pages/ 增加对应 body.html。记录与页面的 path 必须一致。
  3. 需要首页展示时，把路径加入相应 home_lists。首页项目和活动显示 6 条，奖项和任职显示 8 条，其余在 View all 中查看。
  4. 上传图片到 static/assets/，引用地址仍写为 /assets/...。Gallery 的十张原始照片保留全图比例，单行滑动。
  5. 提交源内容后等待自动发布。错误的 JSON、缺失的正文或站内链接会阻止发布。

浏览次数

右下角 Total views 使用自建不蒜子服务统计全站页面访问量（PV），刷新或打开内页会累计，不等于独立访客人数。新计数从 2026-10-29 接入时开始，旧站历史数字没有自动合并。统计设置在 content/settings.json 的 counter 中，正常编辑网页无需修改它。离线显示 Online only；接口或网络故障显示 Unavailable。服务数据存储在第三方后台，本站重新发布不会主动清零。详情见仓库 README。

本地预览与备用编辑助手

本地运行 python3 build.py 后打开 public/index.html。仅需 Python 3.9 及以上，无第三方依赖。图片、导航、搜索和图库可离线浏览。

本地可视化编辑助手保留用于临时预览。它下载的成品 HTML 不会写回源内容，下一次自动生成会覆盖这些改动。长期维护请始终编辑 content/ 和 static/。

域名与发布

正式地址为 https://wentaochen.cn/，托管于 GitHub Pages。规范地址、站点地图和 robots 默认读取 content/settings.json 的 site_url；域名解析与 Enforce HTTPS 在阿里云和 GitHub Pages 设置中管理。仓库中的 README 与 docs/DEPLOYMENT_中文.md 提供完整步骤。
